# AI Insights: The Timeline Pyramid

An interactive project presenting the history and evolution of Artificial Intelligence through a five-layer timeline pyramid.

## Project overview

The pyramid traces the development of AI from its philosophical and mathematical foundations to symbolic systems, machine learning, deep learning, generative AI, large language models, and open questions about AI's future.

## Run the project

No installation or build step is required. Open `index.html` in a modern web browser (Chrome, Firefox, Edge, or Safari). The core interactive experience works offline; external source links require an internet connection.

## Main features

- Five visual pyramid layers showing the progression of AI.
- Clickable milestone cards with explanations.
- Search and layer filters.
- A research register and subfield legend.
- Print / Save as PDF support.
